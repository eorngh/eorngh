# 여행딱 0.1.1 · 신규 서비스 개발판

사용자 2026-10-15 신규 앱·웹 개발 지시로 시작했다. 다른 딱 프로젝트와 별도이며, 기존 소스를 요구하지 않는다.

## 실행·검증
Node 18+ 환경에서 `npm test`, `npm run check` 실행. dist는 빌드 없는 정적 웹이다. HTTPS 정적 호스팅으로 서비스하고 manifest/서비스워커를 제공한다.
홈 → 국내/해외 → 국가·광역지역 → 도시·관광권역 → 달력 → 여행 등록. 내 여행에서 메모 저장·체크·백업·HTML 여행팩 내보내기.

## 실제 구현
- 블루·코랄 브랜드, PC·모바일 반응형, 국가 14개와 국내 광역지역 17개 카드.
- 도시/관광권역, 제한된 보조 검색·기타 지역, 최근 선택 8개.
- 터치 달력, 기간 검증(최대 90일), 여행 저장·목록·삭제.
- 취향 태그 기반 로컬 규칙 추천. 실시간 AI나 유행/계절 조사 결과로 표시하지 않는다.
- 여행별 메모·준비 체크, localStorage 스키마1. 손상된 데이터는 자동 초기화하지 않는다.
- JSON 백업/기기간 이동/추가 가져오기, 동일 ID 기존 여행 덮어쓰기 금지.
- 외부 리소스 없는 HTML 여행팩. 저장된 메모·체크·기본 회화만 포함.
- PWA manifest·192/512px 아이콘·정적 앱 캐시. 오프라인 시 인증과 브라우저 지원 한계 존재.

## 아직 미구현
실시간 AI·관광/행사 수집·자동 갱신·입국 안내·실시간 번역·동선 자동 생성·사진 정리·앨범·Firebase 인증/동기화·Android APK/AAB·Play 테스트. 개발판 화면을 서비스 전체 완성으로 부르지 않는다.

## 개인정보
계정·광고·분석·사진 업로드·API 호출 없음. 여행·메모는 현재 브라우저 저장. 호스팅 접속 처리는 별도. 브라우저 삭제 전 백업 필요. 사용자가 내보낸 HTML/JSON은 개인 자료가 포함될 수 있다. 로컬 데이터는 공개 Site 소스에 포함되지 않는다.

## PC Codex 인계
`handoff/CODEX_MASTER.txt`를 처음 입력하고 `handoff/QA_AND_NEXT.md`를 현재 상태 정본으로 사용한다. 이번 검증은 핵심 로직 8개+DOM 상호작용 7개로 총 15개 통과. 실제 브라우저 렌더링/다운로드/서비스워커/Android를 검증한 것은 아니다.
