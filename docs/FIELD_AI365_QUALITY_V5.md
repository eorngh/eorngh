# 현장AI365 품질혁신 v5 적용 기록

기준일: 2026-10-25 (한국시간). 현장AI365를 여행딱·신규 앱보다 우선한다.
사용자가 제공한 MASTER v5.0을 이번 품질 개선의 요구사항으로 적용한다.
추가 확정 원칙: 공공 API를 데이터 공급의 최우선으로 사용한다. 안전성·데이터
보존 게이트는 유지한다. 민간 유료 API와 생성형 AI는 공식 데이터로 해결되지
않는 업무의 보조 수단으로만 검토하고 연결·비용을 임의 활성화하지 않는다.
기존 프로젝트를 유지하며 전면 재구축하지 않는다. 이번 검토는 한 작업자가
실무·보안·QA 관점을 순차 적용한 것이며 독립 에이전트 검증이 아니다.

## 복구 기준과 변경 범위

- 원격 복구 기준: PR #2, `449f477195fd633065ac9749f4ac0ed96cf66b22`.
- 기존 패키지: `kr.co.hyeonjang.ai365`. 패키지명·서명·운영 Firebase를 변경하지 않는다.
- 모든 변경은 `codex/field-ai365-source-20261023` PR 브랜치에서 검토한다.
- 운영 Firebase 규칙 배포, 사용자 데이터 변경, Play 업로드는 수행하지 않는다.

## 결함 및 우선순위

| ID | 우선순위 | 근거 | 조치 / 합격 기준 |
|---|---|---|---|
| F365-01 | P1 | Storage 규칙의 중괄호 불균형과 default-deny 위치 오류 | 구조 수정. 실제 에뮬레이터에서 컴파일·접근 검사 통과 |
| F365-02 | P0 위험 | 현장등록 초안이 계정과 무관한 localStorage 키 하나를 사용 | 계정·프로젝트별 저장. 이전 무소유 초안은 기기 전용 공간에만 보존 |
| F365-03 | P1 | 등록 최종 제출에 저장 중 중복 실행 방지 없음 | 저장 중 재제출·닫기 차단. 지연된 쓰기에 중복 제출해도 저장 1건 |
| F365-04 | P2 | 768px/글자 2배에서 동기화·알림 버튼이 44px 미만으로 축소 | 버튼 최소 폭과 헤더 줄바꿈. 같은 접근성 검사 재실행 |
| F365-05 | P1 검증 공백 | 기존 CI는 Firebase 규칙 실행·브라우저 검사를 하지 않음 | 별도 CI 작업 및 실패 종료. 누락된 에뮬레이터는 SKIP 금지 |
| F365-06 | P1 검증 공백 | CI Node 20과 앱 요구 Node >=22 불일치 | 앱 검사 Node 22, 격리된 보안 검사 Node >=24.12 및 Java 21 |

초안 저장 공간이 거부되거나 가득 차면 입력을 현재 화면에 유지하고 안내한다.
초안 저장 실패 때문에 IndexedDB 현장 저장까지 막지 않는다. 종료된 등록 화면의
지연 GPS/지도 응답으로 이전 초안 화면이 다시 그려지지 않도록 방지한다.

## 실행 가능한 검사

앱 경로 `apps/field-ai365/`:

```sh
npm ci
npm test
npm run build
node tools/verify-pdf.mjs
```

보안 검사 의존성은 앱과 분리한 `qa/`에만 설치한다. 앱 런타임 의존성은 늘리지 않는다.

```sh
cd qa
npm ci --ignore-scripts
npm run test:rules
```

`demo-field-ai365`만 사용하며 Firestore/Storage는 루프백 포트 8186/9299를 사용한다.
로그인·운영 키·유료 API가 필요 없다. 프록시 환경의 로컬 서비스 간 조회 실패를
규칙 성공으로 오인하지 말아야 한다. 실제 삭제 잠금 검사까지 통과해야 합격이다.
에뮬레이터 검증은 운영 IAM 설정 및 실제 서비스 검증의 대체물이 아니다.

보안 검사 범위: 소유자의 CRUD/목록, 타인·비로그인 접근 차단, 생성과 수정의
자료형·필수 필드·크기·추가 필드 검증, 일곱 업무 컬렉션, 삭제 잠금,
사진 MIME/20MiB 초과, 잠금 후 사진 업로드 차단과 소유자 정리 허용.

기존 Python Playwright 검사 재사용:

```sh
npm start
# 별도 터미널
python tools/browser-check.py
python tools/accessibility-check.py
```

필요하면 `FIELD365_CHROMIUM`으로 설치된 Chromium 실행 파일을 지정한다.
CI는 Playwright 1.64.1을 사용하며 합성 데이터·스크린샷·PDF를 7일간 아티팩트로 보존한다.
브라우저 검사: 현장등록 초안 복원·중복 제출, 일보, 사진 원본 동일성,
사진대지, 거래처·수금·미수금, 견적 금액, PDF 다운로드, 사진 원본 포함
백업/기기 데이터 삭제/복구, 재실행, 5개 화면 폭, 오프라인 재열기.
접근성 검사는 5개 폭 × 5개 화면에서 글자를 2배 확대해 가로 넘침과
44px 터치 영역을 확인하는 제한된 검사이며 전체 접근성 인증은 아니다.

## 기존 증거와 한계

- 기존 자동 검사 85개와 웹 빌드·PDF 조립 검사를 로컬에서 재실행해 통과했다.
- 새 Firestore/Storage 실행 검사 11개가 로컬에서 생략 없이 통과했다.
- `4fd89fc`의 GitHub 실행 `40166960156`: 앱 검사 및 보안 검사 통과.
  브라우저 업무 흐름 32개 통과, 접근성 25개 중 768px 3개 실패.
  위 버튼 수정과 등록 보완 이후의 최신 결과는 PR의 새 CI 로그를 기준으로 판정한다.
- 후속 `e74db88`의 GitHub 실행 `40167417749`: 자동 검사 94개, 보안 검사 11개,
  브라우저 확인 34개, 글자 확대/터치 영역 25개가 모두 통과했다. 이 실행에는
  중복 제출 방지와 원본 포함 백업/삭제/복구, 768px 버튼 수정이 포함된다.
- Android 전용 CI는 기존 소스의 AGP 8.9.2와 PC 릴리즈 스크립트의 Gradle 8.13을
  기준으로 Debug APK 컴파일을 검증한다. 결과는 해당 CI 로그로 확인하며 성공 전에는
  APK가 생성됐다고 주장하지 않는다. Release 서명이나 실기기 설치 검증과 구분한다.
- 실제 PDF 다운로드와 A4 조립 성공은 한글 글리프·다중 페이지의 육안 검수와 구분한다.
- 실제 기기 설치/권한/백그라운드, 실서비스 계정 간 분리 및 다기기 동기화는 미검증이다.

## 다음 출시 게이트

1. 최신 수정본의 자동·보안·브라우저 회귀 검사 모두 통과.
2. 백업 복구 후 원본과 금액 보존, 저장 실패/기기 종료/충돌 복구의 실제 기기 확인.
3. Android 빌드 도구 문서와 실제 버전 통일 후 Debug 빌드·설치·업데이트 확인.
4. 기존 서명 인증서/키의 정본 확인. 임의 신규 서명 생성·교체 금지.
5. 운영 Firebase의 기존 서비스 규칙을 보존한 별도 검증. 공유 Auth 삭제 차단 유지.
6. 정식 개인정보처리방침·계정 삭제 안내·스토어 자료·실제 Play 계정 요구사항 확인.
7. 위 게이트 충족 전에는 출시 준비 완료 또는 비공개 테스트 가능으로 판정하지 않는다.

실시간 AI, EXIF/GPS 자동 사진 분류, 법정 신고 서식, 자동 재접속 동기화는
실제 연결·구현·검증 증거를 확보한 기능만 완료로 표시한다. 주소 샘플과 미연결
공급자는 기존 데모/미연결 표시를 유지한다. 비용·개인정보 전송 범위를 임의 확대하지 않는다.

## 공공 API 우선 적용

1. 현재 구현: 행정안전부 주소 검색 서버 어댑터를 재사용·보완한다. 서버 전용
   `JUSO_SEARCH_KEY`가 없으면 임의의 서울 샘플을 반환하지 않고 미연결/빈 결과로 안내한다.
   Android의 서버 미연결 상태도 동일하게 직접 입력을 안내한다.
2. 정상 응답에 기관·출처 URL·실제 조회 시각을 포함해 선택한 주소와 함께 저장한다.
   주소를 직접 바꾸면 이전 주소의 출처와 행정정보를 제거한다. 캐시 조회는 원래
   확인 시각을 유지한다. 승인키·승인키가 포함된 URL은 응답에 넣지 않는다.
3. 호출 절약: 동일 검색 병합, 프로세스 메모리 5분/100건 캐시, 외부 조회 분당 60건
   제한. 분산 운영의 영속 한도·요금 보장은 아니며 서버 운영 시 별도 검토한다.
4. 다음 공공 API 후보는 기상청 현장 날씨→공간/토지·건축물→지하수 공식 자료 순으로
   이용조건·키·제공 필드·실제 업무 효과를 확인한다. 현재 연결 완료로 표시하지 않는다.
   기상청 공식 목록: https://www.data.go.kr/data/15084084/openapi.do (2026-10-25 확인).
5. 실제 주소 검색 승인키와 Android에서 이용할 HTTPS 서버 연결은 이번 체크아웃에서
   확보되지 않았다. 모의 응답 계약 검증과 실서비스 연결 검증을 구분한다.
